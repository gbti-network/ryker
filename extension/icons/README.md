# Ryker extension icon exports

These are runtime copies of the official Ryker wing mark in `.product/brand/ryker/`.
Chrome needs them inside the extension package, but they are delivery assets and
should not be edited independently. The canonical master, palette, usage rules,
visual reference and generation record live in the product library.

## Files

- `ryker-16.png`: Chrome toolbar size.
- `ryker-32.png`: high-density toolbar size.
- `ryker-48.png`: extension management page size.
- The Chrome exports use a 150% optical scale so the narrow wing reads at a
  comparable size beside other extension marks.
- `ryker-128.png`: Chrome Web Store and installation size.

All visible pixels use RGB `229, 56, 59`. Antialiasing is represented only in
the alpha channel.
